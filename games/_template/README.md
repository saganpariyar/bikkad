# Game Name Template

Use this folder template as a blueprint for adding any new card game to the **Desi Card Games** collection.

## How to use this template:
1. Copy this folder and rename it to your game name (e.g., `games/my_card_game/`).
2. Put your game design prompt(s) in `prompts/prompt.txt`.
3. Put any sample game rounds or play transcripts in `play_logs/sample_logs.txt`.
4. Put the official rules, card ranking, and scoring rules in `rules/rules.txt`.
